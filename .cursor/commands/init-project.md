# Initialisation du projet

Lis tous les fichiers de spécifications du dossier `specs/` pour comprendre le contexte complet du projet :

- [specs/ROADMAP.md](../specs/ROADMAP.md) - Roadmap fonctionnelle & suivi progression
- [specs/PRODUCT_GUIDE.md](../specs/PRODUCT_GUIDE.md) - Guide produit complet
- [specs/BEST_PRACTICES_AUDIT.md](../specs/BEST_PRACTICES_AUDIT.md) - Audit qualité & bonnes pratiques
- [specs/SCORES.md](../specs/SCORES.md) - Scores & métriques détaillées
- [specs/DEPLOYMENT_CHECKLIST.md](../specs/DEPLOYMENT_CHECKLIST.md) - Checklist déploiement
- [specs/TECHNICAL_SPECIFICATIONS.md](../specs/TECHNICAL_SPECIFICATIONS.md) - Spécifications techniques
- [specs/TESTS_GUIDE.md](../specs/TESTS_GUIDE.md) - Guide complet des tests
- [specs/VERCEL_DEPLOYMENT_GUIDE.md](../specs/VERCEL_DEPLOYMENT_GUIDE.md) - Guide déploiement Vercel
- [specs/MCP_GUIDE.md](../specs/MCP_GUIDE.md) - Guide des MCP installés et configurés

Une fois tous ces fichiers lus et le contexte assimilé, lance la commande `/init` pour initialiser le projet.
